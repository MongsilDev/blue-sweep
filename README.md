# Blue Sweep

X 타임라인에서 수익형 파딱 계정을 가려내는 브라우저 확장입니다.
계정 수치와 프로필, 본문 키워드로 점수를 매기고 점수에 따라 표시하거나 숨기거나 차단합니다.
판정은 브라우저 안에서만 하고 외부 서버나 LLM은 쓰지 않습니다.

## 무엇을 잡나

- 맞팔과 답글 품앗이로 노출을 올리는 계정
- 가입한 지 얼마 안 됐는데 하루에 수십, 수백 개씩 올리는 계정
- AI 소식, 투자, 부업을 내세워 팔로워를 모으는 계정
- 테슬라 팬 계정

아래 계정은 건드리지 않습니다.

- 내가 팔로우하는 계정
- 나를 팔로우하는 계정. 이 예외는 패널에서 끌 수 있습니다.
- 기업, 정부 인증 계정
- 파딱이 아닌 계정
- 광고

## 설치

스토어에 올리지 않았기 때문에 폴더를 직접 불러와야 합니다.

1. 이 저장소를 내려받습니다.
2. 확장 관리 페이지를 엽니다. 크롬은 `chrome://extensions`, 엣지는 `edge://extensions`, 웨일은 `whale://extensions`입니다.
3. 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램 로드를 눌러 이 폴더를 고릅니다. 버튼 이름은 크롬 기준입니다.
5. X를 새로고침하면 화면 왼쪽 아래에 버튼이 생깁니다.

Chromium 111 이상에서 동작합니다. 크롬 155, 엣지 155, 웨일 5.39에서 불러와지는 것을 확인했습니다.

## 사용법

왼쪽 아래 버튼을 누르면 패널이 열립니다. 모드는 세 가지입니다.

| 모드 | 동작 |
|---|---|
| 표시만 | 대상 트윗에 테두리와 점수만 붙입니다. |
| 자동 숨김 | 대상 트윗을 한 줄로 접습니다. 접힌 줄을 누르면 펼쳐집니다. 처음 설치하면 이 모드입니다. |
| 자동 차단 | 접고, 차단 기준을 넘은 계정은 차단합니다. |

차단 기준은 6점, 숨김 기준은 5점이고 패널에서 바꿀 수 있습니다.
계정 수치만으로는 차단하지 않습니다. 프로필이나 본문에 수익화, 테슬라, AI, 투자, 광고 문의, 낚시 문구가 있거나 품앗이 답글이어야 차단하고, 이런 내용이 없으면 점수가 높아도 숨기거나 차단하지 않고 표시만 합니다.
패널 목록에서 계정마다 차단, 허용을 따로 누를 수도 있습니다.
최근에 차단한 계정 20개는 새로고침한 뒤에도 패널에 남아 있고, 거기서 바로 해제할 수 있습니다.
차단 요청은 6초에 한 번, 하루 300개까지만 보냅니다.

자동 차단은 자동 숨김으로 며칠 써 보고, 엉뚱한 계정이 걸리지 않는지 확인한 다음 켜는 것을 권합니다.

## 점수

| 신호 | 점수 |
|---|---|
| 팔로잉 500 이상이고 팔로잉의 3배가 팔로워보다 많음 | +2 |
| 가입 180일 미만 / 2년 미만 | +2 / +1 |
| 하루 게시물 80개 이상 / 20개 이상 / 5개 이상 | +4 / +2 / +1 |
| 미디어 게시물 비율 15% 미만 | +1 |
| 수익화, 맞팔 관련 문구 | +3 |
| 테슬라 언급 / 팬임을 드러내는 표현. 이름 속 언급은 팔로워 100만 미만만 셉니다 | +4 / +2 |
| AI 정보 계정 프로필 / 그 밖의 AI, 투자, 코인, NFT, 부업 키워드 | +3 / +2 |
| 광고, 협찬 문의 | +1 |
| 낚시성 문구 | +2 |
| 활동이 많은 계정이 차단 대상 계정에 다는 답글 | +1, 맞팔 구조면 +2 |

키워드와 기준은 전부 `classifier.js`에 있습니다. 취향에 맞게 고쳐 쓰면 됩니다.

## 한계

- 기준은 한 사람의 타임라인에서 모은 표본 몇백 개에 맞췄습니다. 다른 타임라인에서는 결과가 다를 수 있습니다.
- 추천 탭에서 모은 개인 파딱 108개 가운데 차단 대상은 1개였습니다. 맞팔 계정 고정 글의 답글란에서는 19개 가운데 18개가 차단 대상이었습니다.
- 5점대에는 대상이 아닌 계정이 섞입니다. 그래서 5점은 숨기기만 합니다.
- 팔로워가 많은 영어권 AI 계정은 잘 못 잡습니다.
- X 화면의 내부 구조를 읽어서 동작합니다. X가 구조를 바꾸면 멈추고, 그때는 버튼에 안내가 뜹니다.

## 주의

- 차단은 X 내부 API로 보냅니다. X의 자동화 규정에 어긋날 수 있고 계정이 잠길 수 있습니다. 쓰는 사람이 책임져야 합니다.
- 설정과 차단 기록은 브라우저의 x.com 저장소에만 남습니다.
